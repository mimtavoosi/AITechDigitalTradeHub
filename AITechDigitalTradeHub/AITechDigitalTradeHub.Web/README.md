# AITech Digital Trade Hub Web

Next.js frontend for the AITech Digital Trade Hub platform.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- React Query
- Zustand

## Main folders

- `src/app`: routes, layouts, metadata and route groups
- `src/components`: shared UI and feature components
- `src/features`: business feature modules
- `src/lib`: API client, config and utilities
- `src/providers`: app-level client providers
- `src/types`: shared TypeScript contracts

## Commands

```bash
npm install
npm run dev
npm run build
```
