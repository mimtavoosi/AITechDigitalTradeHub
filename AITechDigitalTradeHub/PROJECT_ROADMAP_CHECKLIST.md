این سند، مرجع اجرایی پروژه بر اساس فایل «نهایی پروپوزال.pdf» است و باید در هر جلسه توسعه به‌روزرسانی شود. هدف این است که بدانیم کدام بخش‌ها از بک‌اند، API، دیتابیس، تست، مستندات و بعداً فرانت‌اند انجام شده، در حال انجام است یا باقی مانده.

آخرین به‌روزرسانی: 2026-06-17

- [x] Solution اصلی با نام `AITechDigitalTradeHub.sln` وجود دارد.

- [x] پروژه Data و `DbContext` با نام `TheAppContext` وجود دارد.
- [x] Entityهای اولیه برای Core، Market، Projects، Organization، Finance، Chat، Reviews، Moderation و Analytics ایجاد شده‌اند.
- [x] Migration اولیه وجود دارد.
- [x] Swagger در API فعال شده است.
- [x] Controllerهای API در پروژه ایجاد شده‌اند.
- [x] اتصال `TheAppContext` به DI در `Program.cs` انجام شده است.
- [x] احراز هویت JWT در `Program.cs` فعال شده است.
- [x] Middlewareهای پایه امنیتی، CORS، Exception Handling و Logging فعال شده‌اند.

## تصمیم‌های فنی پایه

- [x] Backend: `ASP.NET Core Web API`
- [x] ORM: `Entity Framework Core`
- [x] Database: `SQL Server`
- [x] API Documentation: `Swagger / OpenAPI`
- [x] Authentication: `JWT + Refresh Token`
- [x] Authorization: Role/Permission based access control پایه
- [x] Authorization چندنقشی: هر کاربر می‌تواند چند نقش تاییدشده همزمان داشته باشد

- [x] Frontend آینده: `Next.js + TypeScript + Tailwind CSS`
- [x] State/Data در فرانت آینده: `React Query` برای API و `Zustand` یا Context محدود برای state داخلی

5. اگر API جدید ساخته شد، در بخش APIهای MVP یا فاز مربوطه تیک بزن.
6. اگر چیزی از پروپوزال تغییر کرد، دلیل تغییر را پایین همین سند اضافه کن.
