# گزارش وضعیت عملیاتی سایت آی‌نت

تاریخ بررسی: ۱۴۰۵/۰۴/۱۳ برابر با 2026-07-04

این سند وضعیت بخش‌هایی را ثبت می‌کند که در کد فعلی سایت و API قابل استفاده هستند. سطح‌ها به این معنی‌اند:

- **عملیاتی در UI و API**: صفحه فرانت و endpointهای اصلی به داده واقعی وصل هستند.
- **عملیاتی در API یا پنل محدود**: منطق بک‌اند آماده است، اما تجربه کامل کاربری هنوز صفحه مستقل یا جریان کامل UI ندارد.
- **نیازمند تکمیل**: مدل یا مسیر اولیه وجود دارد، اما برای استفاده محصولی هنوز کار جدی باقی مانده است.

## 1. صفحات عمومی و SEO

### صفحه اصلی `/`

وضعیت: عملیاتی در UI و API

فرایندها:

- معرفی شبکه تخصصی هوش مصنوعی آی‌نت با تمرکز روی ۸ حوزه اصلی: مشاوره، آموزش، پژوهش، پروژه، فرصت شغلی، سخت‌افزار/زیرساخت، سرمایه‌گذاری و تامین داده.
- نمایش مسیرهای اصلی کاربر برای ورود به پروژه‌ها، خدمات/تجهیزات، آموزش، شرکت‌ها و سرمایه‌گذاری.
- اتصال به پروژه‌های واقعی برای نمایش فرصت‌های منتخب و هدایت کاربر به لیست عمومی پروژه‌ها.
- هماهنگی Header، Navigation Dock، Footer و Sitemap با معماری اطلاعات جدید.

### هاب حوزه‌ها `/domains`

وضعیت: عملیاتی در UI

فرایندها:

- نمایش ۸ حوزه تخصصی به عنوان مسیرهای اصلی محصول.
- هدایت کاربر از حوزه به مقصد عملیاتی مرتبط: خدمات و تجهیزات، پروژه‌ها، آموزش یا سرمایه‌گذاری.
- استفاده در Header و Navigation Dock برای کم‌کردن شلوغی ناوبری سطح اول.

### خدمات و تجهیزات `/services` و `/services/[slug]`

وضعیت: عملیاتی در UI و API

فرایندها:

- دریافت Listingهای واقعی از API مارکت‌پلیس.
- جستجو و مرور خدمات، تجهیزات و پیشنهادهای قابل سفارش.
- نمایش جزئیات خدمت/تجهیز شامل توضیح، قیمت، وضعیت و اطلاعات ارائه‌دهنده.
- ثبت سفارش و پرداخت داخلی از مسیر کیف پول در جریان مارکت‌پلیس.
- مدیریت Listingها و سفارش‌ها از سمت کاربر در داشبورد و از سمت ادمین در پنل مدیریت.

### پروژه‌ها و مناقصه‌ها `/projects` و `/projects/[slug]`

وضعیت: عملیاتی در UI و API

فرایندها:

- نمایش پروژه‌های عمومی واقعی با جستجو، دسته‌بندی، مهارت، نوع پروژه، مدل همکاری، بودجه و مرتب‌سازی.
- بارگذاری تدریجی پروژه‌ها برای کنترل حجم صفحه.
- نمایش جزئیات پروژه، بودجه، مهلت، مهارت‌های لازم، مستندات و شرایط همکاری.
- ارسال پیشنهاد از صفحه جزئیات پروژه همراه اطلاعات اجرایی، رزومه یا نمونه‌کار.
- اتصال جریان پروژه به Proposal، قرارداد، Milestone، Escrow، Deliverable، Timesheet، مستندات، پیام و اختلاف.

### آموزش `/courses` و `/courses/[slug]`

وضعیت: عملیاتی در UI و API

فرایندها:

- نمایش دوره‌های واقعی و جزئیات دوره.
- ثبت‌نام در دوره و پرداخت از کیف پول داخلی.
- کنترل دسترسی محتوای پولی.
- ثبت پیشرفت درس‌محور و محاسبه درصد پیشرفت.
- صدور و استعلام عمومی گواهی.
- رزرو مدرس، پرداخت رزرو، لغو/بازپرداخت و مشاهده رزروهای دانشجو یا مدرس.

### مدرس‌ها `/instructors` و `/instructors/[id]`

وضعیت: عملیاتی در UI و API

فرایندها:

- نمایش مدرس‌ها و پروفایل عمومی مدرس.
- نمایش نشان‌ها، اطلاعات رزومه‌ای و مسیرهای آموزشی مرتبط.
- اتصال به جریان رزرو جلسه آموزشی و پرداخت از کیف پول.

### شرکت‌ها و سازمان‌ها `/companies`

وضعیت: عملیاتی پایه در UI و API

فرایندها:

- معرفی سازمان‌ها و مسیر ورود به پنل شرکت.
- مدل سازمان از حالت فقط شرکت خارج شده و انواع شرکت، دانشگاه، پژوهشگاه، استارتاپ، نهاد دولتی، غیرانتفاعی و شتاب‌دهنده را پوشش می‌دهد.
- API عمومی، مالک، عضو و ادمین برای سازمان‌ها وجود دارد.

### درباره `/about`

وضعیت: عملیاتی در UI

فرایندها:

- توضیح جایگاه محصول، نقش‌ها و حوزه‌های اصلی.
- هدایت کاربر به مسیرهای عملیاتی مثل پروژه، آموزش، خدمات و سرمایه‌گذاری.

### سرمایه‌گذاری `/investment`

وضعیت قبل از این مرحله: مسیر عمومی وجود داشت، اما به API وصل نبود.

وضعیت بعد از این مرحله: عملیاتی در UI و API

فرایندها:

- دریافت فرصت‌های سرمایه‌گذاری باز از API عمومی.
- جستجو در عنوان و خلاصه فرصت.
- فیلتر بر اساس مرحله جذب سرمایه، سطح ریسک، حداقل سرمایه هدف و حداقل ROI مورد انتظار.
- نمایش سرمایه هدف، سرمایه جذب‌شده، درصد پیشرفت جذب، مرحله، ریسک، ROI، مستندات، trancheها و گزارش‌های عمومی.
- نمایش خلاصه فرایند جذب سرمایه، قرارداد، Escrow و گزارش‌دهی برای تصمیم‌گیری اولیه سرمایه‌گذار.

## 2. احراز هویت و حساب کاربری

وضعیت: عملیاتی در UI و API

فرایندها:

- ثبت‌نام دو مرحله‌ای با کد تایید موبایل.
- ارسال و ارسال مجدد کد تایید با ساختار پیامک.
- ورود با نام کاربری، ایمیل یا موبایل.
- صدور JWT و Refresh Token.
- پشتیبانی از نقش‌های چندگانه کاربر در توکن و سیاست‌های دسترسی.
- درخواست قابلیت‌های حساس حساب از `/dashboard/settings` مانند مدرس، ارائه‌دهنده خدمت، سرمایه‌پذیر یا سرمایه‌گذار.
- بررسی و تایید/رد قابلیت‌ها از پنل ادمین.
- تنظیمات اعلان کاربر شامل کانال داخل پنل، ایمیل و SMS، دسته اعلان و ساعات سکوت.

موارد نیازمند تکمیل:

- جریان کامل فراموشی رمز عبور.
- سخت‌سازی امنیتی نهایی شامل rate limiting، سیاست CORS نهایی، محدودیت فایل و لاگ امنیتی کامل.

### پروژه، قرارداد و Escrow

وضعیت: عملیاتی در API و UI داشبورد/ادمین

فرایندها:

- ثبت پروژه.
- ارسال Proposal.
- پذیرش Proposal و ساخت قرارداد.
- ساخت Milestone.
- نگهداری وجه مرحله در Escrow.
- تحویل Deliverable.
- تایید، اصلاح یا اختلاف.
- ثبت Timesheet و Activity Log.
- اختتام قرارداد و ساخت Portfolio.
- داوری و اجرای رای مالی روی Escrow.

### مارکت‌پلیس و سفارش

وضعیت: عملیاتی در API و UI عمومی/داشبورد/ادمین

فرایندها:

- ثبت و انتشار Listing.
- مشاهده عمومی Listing.
- ثبت سفارش.
- پرداخت از کیف پول.
- محاسبه و ثبت کارمزد پلتفرم.
- مدیریت وضعیت Listing و سفارش از پنل ادمین.

### آموزش

وضعیت: عملیاتی در API و UI عمومی/داشبورد/ادمین

فرایندها:

- دوره، درس، ثبت‌نام، پرداخت، پیشرفت، گواهی.
- رزرو مدرس و پرداخت رزرو.
- لغو و بازپرداخت رزرو.
- امتیازدهی دوره/مدرس.
- گزارش آموزشی.

### سرمایه‌گذاری

وضعیت: عملیاتی در API، پنل ادمین و صفحه عمومی

فرایندها:

- ثبت فرصت سرمایه‌گذاری.
- افزودن Pitch Deck و مستندات عمومی/محرمانه.
- تعریف Tranche.
- ثبت گزارش مصرف سرمایه و ROI.
- سرمایه‌گذاری مستقیم با کیف پول و نگهداری مبلغ در Escrow.
- ساخت قرارداد دیجیتال سرمایه‌گذاری.
- ثبت اختلاف سرمایه‌گذاری.
- مدیریت وضعیت فرصت در پنل ادمین.
- نمایش عمومی فرصت‌های باز با فیلتر و اطلاعات تصمیم‌گیری اولیه.

### زنجیره تأمین

وضعیت: عملیاتی در API، نیازمند UI کامل‌تر

فرایندها:

- تخصیص و رزرو منابع.
- اتصال پروژه به خدمات و تجهیزات.
- زمان‌بندی استفاده از منابع.
- جلوگیری از تداخل تخصیص منابع.
- مدیریت ظرفیت ارائه‌دهندگان.
- ثبت هزینه‌های زنجیره تأمین.
- داشبورد جریان ارزش در API.

### پشتیبانی

وضعیت: عملیاتی در API و UI داشبورد/ادمین

فرایندها:

- ثبت، فهرست و جزئیات تیکت.
- دسته‌بندی، SLA، پیوست و گفتگو.
- ارجاع به پشتیبان، مالی یا داوری.
- ثبت رضایت.
- گزارش پاسخ‌گویی و حل.

### پیام‌رسانی و اعلان

وضعیت: عملیاتی در API و UI

فرایندها:

- گفتگوهای مستقل بر پایه Project، Order یا Support.
- ارسال پیام، mark-read و فهرست گفتگوها.
- SignalR برای پیام زنده و مرکز اعلان realtime.
- اعلان داخلی برای پیام، مالی، پروژه، داوری، آموزش و پشتیبانی.
- ارسال ایمیل/SMS مشروط به تنظیمات کاربر و پیکربندی سرویس.

### فایل‌ها

وضعیت: عملیاتی در API و بخش‌های مصرف‌کننده

فرایندها:

## 7. موارد مهم باقی‌مانده

- درگاه پرداخت واقعی و تسویه بانکی واقعی.

- Toast و modalهای عمومی در کل فرانت.

## 8. خلاصه وضعیت محصول

در وضعیت فعلی، سایت فقط مجموعه‌ای از صفحه‌های نمایشی نیست. هسته‌های اصلی محصول شامل احراز هویت، پروژه، مارکت‌پلیس، آموزش، کیف پول، Escrow، پیام، اعلان، تیکت، پنل مدیریت، گزارش‌ها، نشان‌ها، کارمزد، سرمایه‌گذاری و بخشی از زنجیره تأمین در کد و API عملیاتی شده‌اند.

بزرگ‌ترین شکاف‌های باقی‌مانده بیشتر به تکمیل تجربه محصولی، پرداخت واقعی، سیاست‌های عملیاتی مالی، تست‌های انتها به انتها و پنل‌های مدیریتی عمیق‌تر مربوط هستند.
