# مستندات جدول‌های دیتابیس

این فایل از روی `TheAppContextModelSnapshot` تولید شده و شامل نام انگلیسی جدول‌ها، نام فارسی پیشنهادی، کاربرد و ستون‌های هر جدول است.

> نکته: ستون‌های مشترک `ID`, `CreateDate`, `UpdateDate`, `DeleteDate`, `IsActive`, `CreatorId`, `OtherLangs` از `BaseEntity` آمده‌اند و برای بیشتر جدول‌ها تکرار می‌شوند.
